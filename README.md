# Cordel do Sinal 📜

Página web que exibe um cordel original em **redondilha maior**, com tema sobre tecnologia e conexão digital.

## 📖 Sobre

Cordel autoral que explora o paradoxo da era digital: quanto mais conectados, mais distantes do que nos cerca. Escrito em sextilhas de 7 sílabas, no padrão clássico da literatura de cordel.

## 🛠️ Tecnologias

- HTML5
- CSS3

## 🚀 Como executar

Basta abrir o arquivo `index.html` no navegador.
